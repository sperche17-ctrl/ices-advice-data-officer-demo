Reproducible Analysis of ICES Eggs and Larvae Survey Data Using R and Quarto

Author

Sarah Perché

Published

November 19, 2026

Objectives

This report demonstrates data processing, integration, analysis, and reproducible reporting using R and Quarto. Using data from the ICES Eggs and Larvae database, fish egg and larval observations from Denmark, Norway, and Sweden were analysed for the period 2016-2026 to explore spatial and temporal patterns in biodiversity.

Data overview

  • Data source: ICES Eggs & Larvae dataset (ICES Eggs and Larvae dataset [2026]. ICES, Copenhagen)

  • Countries: Denmark, Sweden, Norway

  • Period: 2016-2026

  • Objective: summarise species richness and diversity patterns in Scandinavian fish egg and larval survey data.

Data processing

The EH (haul metadata) and EM (egg and larval measurements) datasets were linked using the common identifier HaulID. Records were filtered to Denmark, Norway, and Sweden and restricted to observations collected between 2016 and 2026. The resulting dataset contained information on sampling location, species identity, developmental stage, and abundance, which were used to calculate biodiversity indicators.

# Import the three survey datasets
eggs_eh <- read.csv(file_list[1])
eggs_em <- read.csv(file_list[2])
eggs_hi <- read.csv(file_list[3])

# Filter EH
eh_scand <- eggs_eh %>%
  filter(
    Country %in% c("DK","NO","SE"),
    Year >= 2016,
    Year <= 2026
  )

# Join with SI using common keys
final_data <- eh_scand %>%
  left_join(
    eggs_em,
    by = c(
      "HaulID")
  )

# Keep only variables for analysis
final_data <- final_data %>%
  select(
    HaulID,
    Survey,
    Country,
    Month,
    Year,
    Species,
    ELSampleFlag,
    Number
  )

Biodiversity index

Species richness measures the number of species present in a community, while the Shannon diversity index accounts for both species richness and the relative abundance of each species. Together, these metrics provide complementary measures of biodiversity.

Species richness

richness_country <- final_data %>%
  group_by(Country, Year) %>%
  summarise(
    Richness = n_distinct(Species),
    .groups = "drop"
  )

ggplot(richness_country,
       aes(x = Year,
           y = Richness)) +
  geom_line(colour = "steelblue",
            linewidth = 1) +
  geom_point(colour = "steelblue",
             size = 2) +
  facet_grid(Country ~ .) +
  plot_base_theme() +
  labs(
    title = "Species Richness Through Time by Country",
    x = "Year",
    y = "Species Richness"
  )

Results

Species richness differed among countries and years. Norway generally showed the highest richness, with up to nine recorded taxa, whereas Denmark and Sweden typically recorded between six and eight taxa. Temporal fluctuations were observed in all three countries, indicating variation in species occurrence across the study period.

Shannon diversity

shannon_data <- final_data %>%
  group_by(Country, Year, Species) %>%
  summarise(
    Abundance = sum(Number, na.rm = TRUE),
    .groups = "drop"
  )

shannon_index <- shannon_data %>%
  tidyr::pivot_wider(
    names_from = Species,
    values_from = Abundance,
    values_fill = 0
  ) %>%
  group_by(Country, Year) %>%
  group_modify(~{
    data.frame(
      Shannon = vegan::diversity(
        as.matrix(.x[, !(names(.x) %in% c("Country","Year"))]),
        index = "shannon"
      )
    )
  })

ggplot(shannon_index,
       aes(x = Year,
           y = Shannon)) +
  geom_line(colour = "darkgreen",
            linewidth = 1) +
  geom_point(colour = "darkgreen",
             size = 2) +
  facet_grid(Country ~ .) +
  plot_base_theme() +
  labs(
    title = "Shannon Diversity Through Time by Country",
    x = "Year",
    y = "Shannon Index"
  )

Results

The Shannon diversity index varied over time in all three countries. Higher values indicate a more even distribution of individuals among species, whereas lower values indicate that observations were dominated by relatively few taxa. Overall, the results suggest temporal variation in community composition across Scandinavian waters.

Conclusion

Using ICES Eggs and Larvae survey data, this analysis demonstrated a reproducible workflow for data integration, filtering, biodiversity analysis, and reporting in R. Species richness and Shannon diversity varied among countries and years, with Norway generally exhibiting the highest species richness. The workflow illustrates how biological survey data can be transformed into information that supports scientific assessment and evidence-based advice.
